\section{Knowledge Base and FAISS Indexing}
\label{ch:knowledge-base}

\subsection{Training-only memory}
The knowledge base contains CLIP vectors for 10,000 training images and 50,000 training captions, linked to IDs and metadata. Validation and test references are excluded to support leakage-safe experiments.

\subsection{Exact search}
FAISS stores and searches vectors. Both indexes use \code{IndexFlatIP}, a flat, exact inner-product index. With unit-normalized vectors, inner product equals cosine similarity:
\[
  \operatorname{cos}(q,v)=q^\top v
  \qquad \text{when } \lVert q\rVert_2=\lVert v\rVert_2=1.
\]
The image index contains 10,000 vectors of dimension 512. The caption index contains 50,000 vectors of dimension 512. The index metadata records the source split, model, vector dimension, metric, and mappings. The recorded file sizes are 20,480,045 bytes for the image index and 102,400,045 bytes for the caption index.
