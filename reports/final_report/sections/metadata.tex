\section{Metadata Extraction}
\label{ch:metadata}

\subsection{Fields and provenance}
Each image record links its COCO ID, filename, split, dimensions, and object records. Other fields come from pixel analysis, box geometry, or CLIP predictions; these sources are not interchangeable. In particular, a CLIP score is not a calibrated probability.
