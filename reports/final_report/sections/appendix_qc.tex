\section{Run commands}
From the project root, available stages can be inspected with:
\begin{lstlisting}[basicstyle=\ttfamily\small,frame=single,backgroundcolor=\color{ProjectGrey}]
python main.py --help
\end{lstlisting}

Focused analysis commands documented by the project include:
\begin{lstlisting}[basicstyle=\ttfamily\small,frame=single,backgroundcolor=\color{ProjectGrey}]
python main.py extended_analysis
python main.py quality
\end{lstlisting}

From the report folder, compile with \code{latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex} when latexmk is installed, or use the Tectonic command shown in the report README.
