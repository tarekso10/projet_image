# LaTeX source bundle

This directory contains the active source inputs and figures used for the final report. Compile from this directory with `tectonic main.tex` when Tectonic 0.17.0 and the required LaTeX packages are available. The bundle was checked against the existing `reports/final_report/overleaf_upload.zip`; every overlapping source/asset file has the same SHA-256. The checked-in PDF is the already-built final artifact.
