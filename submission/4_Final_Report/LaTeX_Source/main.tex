\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}
This report presents Phase 1 of a project on retrieval-augmented image captioning using 10,000 training, 100 validation, and 1,000 test images from MS COCO 2017. The 11,100 selected images have 55,500 reference captions. The pipeline preprocesses images, preserves raw captions, organizes metadata, creates normalized 512-dimensional CLIP embeddings, and builds training-only FAISS indexes. Pipeline quality checks pass for the implemented tests, while overall assignment compliance remains \textbf{PARTIAL}. A top-5 retrieval smoke test on 20 held-out queries had zero self-matches and mean top-1 cosine similarity 0.8260; this is not a caption-quality measure. Caption generation, RAG comparisons, and statistical evaluation remain future work.
